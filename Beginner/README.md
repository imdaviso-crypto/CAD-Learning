# Project 001 – Dice

## Objective

Create my first CAD model while learning the fundamental SolidWorks workflow.

## Project Description

This project is the beginning of my CAD portfolio.

Version 1 focuses on creating a precise 20 mm × 20 mm × 20 mm cube with rounded edges while learning the core modeling workflow used in SolidWorks.

Future versions of this project will transform the cube into a fully detailed die.

---

## Skills Learned

- Sketches
- Smart Dimensions
- Coincident Relations
- Extruded Boss/Base
- Fillet

---

## Version History

### Version 1

- Created a 20 mm × 20 mm × 20 mm cube
- Added rounded edges using Fillet
- Learned how to fully define a sketch

---

## Future Improvements

- Add dice pips using Extruded Cut
- Create engineering drawings
- Export for 3D printing
- Apply material appearance
- Calculate mass properties

## Reflection

This project taught me that CAD is not simply drawing objects—it is defining geometry with precise dimensions and relationships.
